# Link

Links define the type of relation/connection that can exist between different Units

## Persistence
When you create a Relation link their information are stored inside our Database, according to the defined project, inside
the `arke_link` table.

We have the `type` column that store the link_id, the `parent_id`/`child_id` that store the unit that we want to link to
and `metadata` that define additional link information.

![ArkeDBView](/entities/link/db_view_1.png)

## RESTful Endpoints

When you create a Link a set of default API are generated to manage it, the API could be authenticated and could have
restricted permissions, additional params are ready-to-use like sorting, filtering and more.
Discover them in the dedicated [RESTful API](/restful-api/link) section.
