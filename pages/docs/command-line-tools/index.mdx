# Installation
**arkectl** is the official CLI for Arke. It is a command-line tool that allows you to interact with Arke from a terminal
window. It allows you to create new frontend/backend projects, start the console or call utilities.

Contribute on [Github](https://github.com/arkemishub/arkectl)

<Tabs items={['Go', 'Homebrew']}>
  <Tabs.Tab>
    <Steps>
    ### Download
    ```go
    go install github.com/arkemishub/arkectl@latest
    ```

    ### Define ARKEPATH
    <Tabs items={['MacOS', 'Windows']}>
        <Tabs.Tab>
            Expose a new variable called ARKEPATH within your ~/.zshrc

            ```bash
            export ARKEPATH=$HOME/arke
            ```
        </Tabs.Tab>
        <Tabs.Tab>
            <Callout type="error">
                Use Windows command prompt instead of Powershell cause there are some troubles.
            </Callout>

            Open the command line and run `sysdm.cpl`
            ![RunCommand](/command-line-tools/run_command.png)

            Open the Environment variables from Advanced tab
            ![SystemProperties](/command-line-tools/system_properties.png)

            Add a new variable with name `ARKEPATH` and value `C:\Users\<YOUR_USER>\arke`:
            ![EnvironmentVariables](/command-line-tools/environment_variables.png)
        </Tabs.Tab>
    </Tabs>

    ### Install
    Install arkectl to download required files to run Arke and verify the correct install:
    ```
    arkectl install

    arkectl -v
    arkectl version 0.0.9
    ```
    </Steps>
  </Tabs.Tab>
