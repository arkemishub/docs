## Authenticate a member - Sign-in Credentials

<RestfulApiContainer>
    <div>
        The "Authenticate a member" endpoint enables users to securely authenticate and access their accounts within

        #### Headers
        <RestfulApiTable
            columns={HEADERS_COLUMNS}
            rows={HEADERS_ROWS}
        />

        #### Body
        <RestfulApiTable
            columns={BODY_COLUMNS}
            rows={[

                {key: 'password', value: '<YOUR_PASSWORD>' },
            ]}
        />

        Upon successful authentication, the response contains an access token which should be included in subsequent requests
        for authorized access to protected resources.
        It's recommended to use HTTPS to ensure secure transmission of credentials.
        Always validate user input and sanitize data to prevent injection attacks.

        #### HTTP Response status
        <RestfulApiTable
            columns={HTTP_RESPONSE_COLUMNS}
            rows={HTTP_RESPONSE_ROWS}
        />

    </div>
    <div>
        <RestfulApiRequest
            title={`Code samples for "Authenticate a member"`}

            path="/api/lib/auth/signin"
        >
            <Tabs items={['cURL', '@arkejs/client', 'fetch']}>
                <Tabs.Tab>
                    ```bash
                    curl --location 'https://arkehub.com/api/lib/auth/signin' \
                    -H "Arke-Project-Key: <YOUR_PROJECT_ID>" \
                    -H 'Content-Type: application/json' \
                    --data-raw '{
                        "username": "user@arkehub.com",
                        "password": "my_secret_password_123!",
                    }'
                    ```
                </Tabs.Tab>
                <Tabs.Tab>
                    ```js
                    client.auth.signIn({
                        username: "user@arkehub.com",
                        password: "my_secret_password_123!",
                    }, 'credentials', config)
                    .then((response) => console.log(response.data)
                    .catch((error) => console.error(error));
                    ```
                </Tabs.Tab>
                <Tabs.Tab>
                    ```js
                    const myHeaders = new Headers();
                    myHeaders.append("arke-project-key", "<YOUR_PROJECT_ID>");
                    myHeaders.append("Content-Type", "application/json");

                    const raw = JSON.stringify({
                    "username": "user@arkehub.com",
                    "password": "my_secret_password_123!",
                    });

                    const requestOptions = {
                    method: "POST",
                    headers: myHeaders,
                    body: raw,
                    redirect: "follow"
                };

                    fetch("https://arkehub.com/api/lib/auth/signin", requestOptions)
                    .then((response) => response.text())
                    .then((result) => console.log(result.data))
                    .catch((error) => console.error(error));
                    ```
                </Tabs.Tab>
            </Tabs>
        </RestfulApiRequest>

## Authenticate a member - One-Time-Password (OTP)

<RestfulApiContainer>
    <div>
        If OTP methods it enabled on your backend, the signin credentials needs an additional `otp` key to authenticate
        the member.

        To authenticate your account with OTP method, you have to call the sign in API two times.

        On the first time you can provide the standard username/password combination with the `otp` key set to null.
        If user exist, this request send an email to your account containing a alphanumeric/numeric code that you have
        to use in seconds request.

        Repeat the sign in API call setting the `otp` key with the code received by email. If it is correct the user will
        be authenticated and you'll receive the member session on the response

        <RestfulApiTable

    <div>
        <RestfulApiRequest
            title={`Code samples for "Verify token"`}
            method="post"
            path="/api/lib/auth/verify"

                    ```bash
                    curl --location 'https://arkehub.com/api/lib/auth/verify' \

                    -H 'Content-Type: application/json' \
                    ```
