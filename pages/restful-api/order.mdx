## Order

<div>
    The "Order" params is the simplest way to sort items in your GET all responses. The
    most common use is when you want Sorting in ascending or descending order the response.

    #### Params
    <RestfulApiTable
        columns={BODY_COLUMNS}
        rows={[
            {key: 'order', value: '<PARAMETER_ID>;asc' },
        ]}
    />

    Use the `asc/desc` key and the parameter ID to define the order.
</div>

### Multiple order
If you need multiple sorting you can use an array of order params:

```js
[{order: 'name;desc'},{order: 'date;asc'}]
```
<Callout type="info">
    Use a `paramsSerializer` to stringify the array in the request
</Callout>

On params we'll have a definition as:
```
order[]=name%3Bdesc&order[]=date%3Basc
```
