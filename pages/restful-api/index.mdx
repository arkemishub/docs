# RESTful API

RESTful (Representational State Transfer) endpoints are a key architectural style for designing networked applications.
They are based on a set of principles that establish a uniform interface between clients and servers. RESTful's endpoints
provide a standardized way for clients to interact with resources on a server over the HTTP protocol, making them widely
adopted for building scalable and interoperable web services.

You can use Arke APIs to interact with your backend application to create and manage your entities, automate processes,
integrate other services, and extend Arke application. In this section you'll find all autogenerated APIs available on
Arke, with their definition and methods.

<Callout type="info">
    Swagger UI<br/>

</Callout>

This article describes how to quickly get started with the Arke REST API using curl, our @arkejs/client, or JavaScript.

## Before starting

Discover the follows steps to authenticate and validate your request using the ArkeProjectKey and the Authorization headers.

### Define your Project
To properly execute an API call on Arke you have always defined the `arke-project-key` in your Request Headers. This identifies
your active [project](/docs/multi-tenant) in the multi-tenant environment.

![RestfulProjectFlow](/restful-api/restful-project-flow.png)

<Tabs items={['cURL', '@arkejs/client', 'fetch']}>
    <Tabs.Tab>
        ```bash
        curl --location 'https://arkehub.com/api/lib/arke/unit' \
        -H 'arke-project-key: {{my-project}}'
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        import { Client } from "@arkejs/client";

        const client = new Client({
            serverUrl: "https://arkehub.com/api/lib/arke/unit",
            // This will create an interceptor that append arke-project-key
            project: "my-project",
        })
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        const myHeaders = new Headers();
        myHeaders.append("arke-project-key", "daikin-develop");

        const requestOptions = {
            method: "GET",
            headers: myHeaders,
            redirect: "follow"
        };

        fetch("https://arkehub.com/api/lib/arke/unit", requestOptions)
        .then((response) => response.text())
        .then((result) => console.log(result))
        .catch((error) => console.error(error));
        ```
    </Tabs.Tab>
</Tabs>

### Authenticate your request

According to Arke defined [permission](/docs/members-and-permissions/permissions) you have to authenticate the request.
So, if arke is defined as public you have not to do it, instead you have to append the access_token (obtained by signin)
on the Authorization header.

![RestfulAuthFlow](/restful-api/restful-auth-flow.png)

<Tabs items={['cURL', '@arkejs/client', 'fetch']}>
    <Tabs.Tab>
        ```bash
        curl --location 'https://arkehub.com/api/lib/arke/unit' \
        -H 'Authorization: Bearer {{access_token}}'
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        import { Client } from "@arkejs/client";
        import { getSession } from "next-auth/react";

        const client = new Client({
        serverUrl: "https://arkehub.com/api/lib/arke/unit",
        project: "my-project",
        // Use this method to defined how to retrieve the session
        // This will create an interceptor that append access_token key
        getSession: async () => {
            // Get user data session stored after sign-in
            const userSession = getSession();
            return userSession;
        },
    })
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        const headers = new Headers();
        headers.append("Authorization", "Bearer {{access_token}}");

        const requestOptions = {
        method: "GET",
        headers: headers,
        redirect: "follow"
    };

        fetch("https://arkehub.com/api/lib/arke/unit", requestOptions)
        .then((response) => response.text())
        .then((result) => console.log(result))
        .catch((error) => console.error(error));
        ```
    </Tabs.Tab>
</Tabs>
