# RESTful API

You can use Arke APIs to interact with your backend application to create and manage your entities, automate processes,
integrate other services, and extend Arke application. In this section you'll find all autogenerated APIs available on
Arke, with their definition and methods.

<Callout type="info">
    Swagger UI<br/>
    When you run an Arke backend application you can find a SwaggerUI instance on
    [http://localhost:4000/api/lib/doc/swaggerui](http://localhost:4000/api/lib/doc/swaggerui)
</Callout>

This article describes how to quickly get started with the Arke REST API using curl, our @arkejs/client, or JavaScript.

### Define your Project
To properly execute an API call on Arke you have to define the `arke-project-key` in your Request Headers. This identifies
your active [project](/docs/multi-tenant) in the multi-tenant environment.

<Tabs items={['cURL', '@arkejs/client', 'fetch']}>
    <Tabs.Tab>
        ```bash
        curl --location 'https://arkehub.com/api/lib/arke/unit' --header 'arke-project-key: {{my-project}}'
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        import { Client } from "@arkejs/client";

        const client = new Client({
            serverUrl: "https://arkehub.com/api/lib/arke/unit",
            project: "my-project",
        })
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        const myHeaders = new Headers();
        myHeaders.append("arke-project-key", "daikin-develop");

        const requestOptions = {
            method: "GET",
            headers: myHeaders,
            redirect: "follow"
        };

        fetch("https://arkehub.com/api/lib/arke/unit", requestOptions)
        .then((response) => response.text())
        .then((result) => console.log(result))
        .catch((error) => console.error(error));
        ```
    </Tabs.Tab>
</Tabs>

### Authenticate your request

According to Arke defined [permission](/docs/members-and-permissions/permissions) you have to authenticate the request.
So, if arke is defined as public you have not to do it, instead you have to append the access_token (obtained by signin)
on the Authorization header.

<Tabs items={['cURL', '@arkejs/client', 'fetch']}>
    <Tabs.Tab>
        ```bash
        curl --location 'https://arkehub.com/api/lib/arke/unit' --header 'Authorization: Bearer {{access_token}}' \
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        import { Client } from "@arkejs/client";
        import { getSession } from "next-auth/react";

        const client = new Client({
        serverUrl: "https://arkehub.com/api/lib/arke/unit",
        project: "my-project",
        // Use this method to defined how to retrieve the session
        getSession: async () => {
            // Get user data session stored after sign-in
            const userSession = getSession();
            return userSession;
        },
    })
        ```
    </Tabs.Tab>
    <Tabs.Tab>
        ```js
        const headers = new Headers();
        headers.append("Authorization", "Bearer {{access_token}}");

        const requestOptions = {
        method: "GET",
        headers: headers,
        redirect: "follow"
    };

        fetch("https://arkehub.com/api/lib/arke/unit", requestOptions)
        .then((response) => response.text())
        .then((result) => console.log(result))
        .catch((error) => console.error(error));
        ```
    </Tabs.Tab>
</Tabs>
